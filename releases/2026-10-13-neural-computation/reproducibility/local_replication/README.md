# 本地复跑

## 用途

重新执行原服务器删除后缺少可核验执行资料的实验。所有新结果写入
`results_local_replication_20261009/`。旧论文、旧结果和旧归档保持原样。

新进化的网络必须与新测量配对。没有原55个邻接矩阵及其哈希，无法把同种子生成的矩阵认定为原矩阵。
本地采用Python 3.12.14、NumPy 1.26.4、Gymnasium 1.2.2；关联测量另用SciPy 1.13.1。
它们是本次执行的固定环境，原服务器的完整环境版本无法确认。

## 本轮准备

- 原24个电流实验网络、144个损伤变体及冻结参数已提取并校验。
- 注入器修正前的源码保存在`source_before_fix/`；实际执行源码及哈希保存在`source_execution/`。
- 数值测试覆盖关闭注入、精确替换、零计数平局、多输出通道、随机方向刷新和逐内部步强度检查。
- 两个关联队列的GA记录器均与原算法产生完全相同的试跑拓扑和得分。
- 主队列测量和c2终验入口已通过端到端检查；这两项使用的是一代GA试跑网络。

试跑网络存放在`association/smoke/`，不会被正式测量入口当作完整预算的网络使用。
24条件、48回合的电流基准位于`current/benchmark/`；单谱系的6变体、20回合试跑位于`current/single/`。
全量目录为`current/full/`与`association/full/`。

## 修正与保留

1. 全零参考输出计数仍按argmax最低索引选择动作，动作对齐控制不再因为全零计数漏掉校正。
2. 随机方向每个环境步抽取一次，在20个内部步中保持方向、逐步匹配精确校正的L2范数。
   修正前方向跨环境步和回合保留。新旧条件有实质差别，必须重新比较。
3. 三类等强度控制逐内部步检查范数；关闭注入时的记录改为实际零注入，不改变原生轨迹。
4. 保留原GA、输入编码、膜电位更新、读出、训练种子和原32组删除定义。
   删除剂量同时保存全部HH边和覆盖边两种分母。
5. 现存c2进化代码的选择段89000–89009与测量段89000–89019重叠10个回合。
   本次同程序复跑明确记录该情况，并单列89100–89119终验段。终验是同网络的新评估，不是新拓扑样本。
6. 原GA按整代完成训练，因此20,000的预算在现实现中通常实际执行20,040个训练回合；
   最终候选选择另有评估。分别记录请求预算、实际训练回合和全部逐回合回报。
7. 完成的电流cell、进化网络和测量结果通过配置和身份检查后可跳过。
   原GA检查点没有完整随机状态与候选档案；中断的网络会从头重跑，并保留旧尝试目录。
8. 2026-10-12增加校准窗口边界检查，只剔除无法重放完整6步的采样窗口。
   有效窗口须至少250个；不补齐观测、不更换起点、不新增回合。
   原始校准另存为`calibration_original.json`，实际使用的数据为`calibration.json`，
   `calibration_window_audit.json`记录筛除数量和位置。修正配置另存，不覆盖原配置。
   已有结果仅在所有窗口有效、参数及其他源码未变且拓扑身份一致时保留使用，
   检查记录位于`measurement_reuse_checks/`，原结果文件与原哈希不改写。

## 运行

在项目根目录执行。全部阶段较长，不会因为打开或导入文件而自动启动。

```powershell
.\.venv_local_replication\Scripts\python.exe -m local_replication.run_all --workers 4
```

只运行全量电流条件：

```powershell
.\.venv_local_replication\Scripts\python.exe -m local_replication.run_all --stage current --workers 4
```

只运行55个网络及其测量、终验和统计：

```powershell
.\.venv_local_replication\Scripts\python.exe -m local_replication.run_all --stage association --workers 4
```

独立复查仪器：

```powershell
$env:OMP_NUM_THREADS='1'
$env:OPENBLAS_NUM_THREADS='1'
$env:MKL_NUM_THREADS='1'
.\.venv_local_replication\Scripts\python.exe -m unittest local_replication.test_injector -v
```

每个数学库限制为单线程，默认4个并行进程。程序遇到不一致配置、缺少结果或强度断言失败会停止，
不把残缺文件算作完成。统计分析以网络谱系为独立单位；单谱系试跑不计算显著性。

  新结果的关联、协变量调整和跨评估段配对单独报告，不接入旧CSV。
